# IndexNow publication record

PopIntent uses IndexNow only to notify participating search engines when a public website URL is added or updated. It does not send browser-extension activity, user data, or private URLs.

- Host: `snncs.github.io`
- Key file: `https://snncs.github.io/PopIntent/dbddff1968f647eb84acee9eaa958058.txt`
- Submission endpoint: `https://api.indexnow.org/indexnow`
- URLs are submitted with an explicit `keyLocation` because this GitHub Pages site is published below `/PopIntent/` rather than at the host root.

Record the date, submitted URLs, and HTTP response after each manual submission. HTTP 200 means the endpoint received the URL set; it does not guarantee indexing or ranking.
